# 💥 Базука 3D

![Version](https://img.shields.io/badge/version-1.0.0-orange)
![License](https://img.shields.io/badge/license-MIT-blue)
![Platform](https://img.shields.io/badge/platform-Web-brightgreen)

Трехмерная игра-песочница с разрушаемым окружением, созданная на Three.js. Разрушайте город из базуки, призывайте метеориты, спавните людей и взаимодействуйте с NPC через чат!

## 🎮 Особенности

- **Разрушаемое окружение**: Взрывайте здания и разбрасывайте ящики
- **Система сохранений**: Сохраняйте прогресс в локальном хранилище браузера
- **Специальные режимы**: 
  - 👑 Режим Бога (бесконечные патроны, полет)
  - ⭐ Расширение территории (магическая пентаграмма, ускорение)
- **Метеоритные атаки**: Призывайте небесные тела для массовых разрушений
- **NPC с чатом**: Общайтесь с выжившими через встроенный чат
- **Полное управление**: WASD + мышь + специальные клавиши

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| `WASD` | Передвижение |
| `Мышь` | Поворот камеры |
| `ЛКМ` | Выстрел из базуки |
| `R` | Перезарядка |
| `G` | Режим Бога |
| `H` | Расширение территории |
| `E` | Вызов метеорита |
| `F` | Спавн людей (в спец. режимах) |
| `T` | Восстановление города |
| `P` | Чат с NPC |
| `Space` | Полет вверх (режим Бога) |
| `Shift` | Полет вниз (режим Бога) |
| `Esc` | Пауза/Меню |

## 🚀 Быстрый старт

1. Скачайте HTML-файл
2. Откройте в современном браузере (Chrome, Firefox, Edge)
3. Примите условия использования
4. Нажмите "ИГРАТЬ" или "ПРОДОЛЖИТЬ"

## 💾 Система сохранений

Игра автоматически сохраняется в локальное хранилище браузера:
- Нажмите `⋮ МЕНЮ` → `СОХРАНИТЬ ПРОГРЕСС`
- При следующем запуске нажмите `ПРОДОЛЖИТЬ`

**Сохраняемые данные:**
- Количество патронов
- Позиция и поворот игрока
- Состояние всех зданий
- Активные режимы
- Количество живых NPC

## 🛠 Технологии

- **Three.js v0.128.0** - 3D-движок
- **WebGL** - Рендеринг
- **LocalStorage API** - Сохранение прогресса
- **Pointer Lock API** - Управление мышью
- **Чистый JavaScript (ES6 модули)** - Игровая логика

## 📦 Структура проекта

## 🎨 Игровые механики

### Разрушение зданий
- Здания имеют HP и разрушаются от взрывов
- Разрушенные здания меняют цвет и деформируются
- Разные режимы имеют разный радиус взрыва

### NPC система
- 30 случайно расположенных NPC
- Реагируют на ключевые слова в чате
- Могут погибнуть от взрывов
- Случайно общаются между собой

### Режим Бога
- Бесконечные патроны
- Возможность летать (Space/Shift)
- Увеличенная скорость передвижения (2x)
- Улучшенные взрывы

### Расширение территории
- Магическая пентаграмма вокруг игрока
- Скорость передвижения 6x
- Супер-мощные взрывы
- Массовый спавн людей

## ⚙️ Производительность

- Оптимизировано для мобильных устройств
- Низкополигональные модели
- Ограничение дальности прорисовки
- Адаптивная частота кадров

## 🔒 Безопасность

- Все данные хранятся локально
- Нет отправки данных на сервер
- Предупреждение о возрасте 16+

## 🐛 Известные проблемы

- Может тормозить на слабых устройствах при большом количестве объектов
- Сохранения могут быть потеряны при очистке кэша браузера
- Нет мультиплеера (только локальная игра)
